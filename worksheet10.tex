\begin{exercise}
    Prove that if an infinite series converges, then the associative property holds.  Assume $a_1 + a_2 + \cdots $ converges to a limit $L$, i.e. the sequence of partial sums $s_n := x_1 + \cdots x_n$ converges to $L$.  Show that any regrouping of the form
    \begin{align*}
        (a_1 + \cdots a_{n_1}) + (a_{n_1+1} + \cdots + a_{n_2}) + \cdots
    \end{align*}
    leads to a series that also converges to $L$.
\end{exercise}

\begin{exercise}
    Decide whether the following statements are true or false. Provide counterexamples for those
that are false, and supply proofs for those that are true.
\begin{enumerate}
    \item  An open set that contains every rational number must necessarily be all of $\mathbb{R}$.
    \vfill
\item The Nested Interval Property remains true if the term “closed interval” is replaced by
``closed set.”
\vfill
\item Every nonempty open set contains a rational number.
\vfill
\item  Every bounded infinite closed set contains a rational number.
\vfill
\item The Cantor set is closed.
\vfill
\end{enumerate}
\end{exercise}
